# ArtFolio — Keegan's Art Showcase

A cinematic, single-page art portfolio with drag-and-drop uploads, parallax scroll, and a full-screen lightbox.

## Features

- 🎨 **Drag & drop** artwork directly into the browser
- ✨ **Cinematic intro** with animated name reveal
- 🖼️ **Parallax scroll** and scroll-triggered card animations
- 🔍 **Full-screen lightbox** with keyboard navigation
- 📱 **Responsive** — works on mobile and desktop
- 🌙 **Dark gallery** aesthetic designed for visual art

## How to use

1. Open `index.html` in any modern browser
2. Drag and drop images onto the upload zone
3. Click any artwork to view in full-screen lightbox
4. Use arrow keys or on-screen buttons to navigate

## No server needed

This is a pure static HTML/CSS/JS file. No build step, no dependencies, no backend. Works completely offline once loaded.

## Customizing

- Edit the `<title>` and intro text directly in `index.html`
- Change the color scheme by editing CSS custom properties in `:root`
- Replace the intro gradient words or animations as desired
